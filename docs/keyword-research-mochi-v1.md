## 0. 方法论与边界

- **不依赖付费工具**：本环境无 GKP / Ahrefs / Semrush 接口，且项目处于冷启动，买工具不划算。
- **信号来源（公开可获得）**：
  1. 竞品分类结构：CrazyGames（7000+ 库，分类含 .io / Puzzle / Arcade / Racing / Sports / Idle / Word / Shooting）、Poki（1500+ 库，分类含 Racing / Puzzle / Action / Endless Runner / 2-Player / Dress-up / Cooking / Sports）。
  2. Google Trends 类趋势文与「2026 热门」聚合页高频词。
  3. Unblocked 搜索集群（学校 / Chromebook 场景）：大量「unblocked games for school」「games not blocked on Chromebook」「io games unblocked」类查询，且每个学校日有搜索高峰。
  4. 玩法类型高频词：2048、merge、bubble shooter、block puzzle、match-3、snake、flappy、stickman、slope、eggy car 等跨多站反复出现。
- **不纠结精确量/KD**：只做信号级判断（高/中/低竞争、冷启动可切入性）。
- **商业对齐**：双广告变现（游戏内 GD + 站内 AdSense）+ 原创定位 → 关键词策略按「玩法类型 / 品类 / 场景」建页，而非去抢具体品牌游戏词（Subway Surfers、Shell Shockers 等大站霸占，新站难切入）。我们的原创游戏覆盖这些玩法类型，每页吃品类搜索流量。

## 3. 商业目标过滤（交叉对比用基线）

**保留标准（最终库候选）**：
1. 能吃品类/场景流量，不依赖单一品牌词；
2. 对应我们有或能自创的玩法类型（原创合规）；
3. 适合广告嵌入——玩家停留时长中高（解谜/合并/io 优于纯瞬时）；
4. 长尾词能支撑独立游戏页或品类页（≥250 词内容可写）。

**建议排除/弱优先**：
- 纯品牌导航词（Subway Surfers、Shell Shockers、Krunker、Papa's 等）：大站霸占，新站冷启动难切，除非做「玩法近似原创页」间接吃。
- 成人/赌博向：不符站定位。
- 重度 3D 射击（Bullet Force、1v1.LOL）：自创成本高、移动端重，冷启动不优先。

**与现有 8 游戏的直接映射**（可立即建页吃流量）：
- merge-numbers → 主题 1/2（2048 + merge）
- neon-snake → 主题 7（snake）
