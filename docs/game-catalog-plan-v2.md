## 一、对 ChatGPT 原始建议的评估

| 维度 | 评估 |
|------|------|
| **方向** | ✅ 正确。Puzzle + Arcade 占大头，符合浏览器休闲游戏大盘与我们的自研能力。 |
| **数量** | ✅ ≥50 款符合「超市逻辑」与 GD 重审门槛策略。 |
| **颗粒度** | ⚠️ 太粗。只有品类配额，没有具体要吃的搜索词/游戏机制，无法直接落地。 |
| **SEO 适配** | ❌ 缺失。没有映射到 unblocked / no download / school / Chromebook 等高价值场景词。 |

**结论**：建议按下方细化版执行，而不是直接按原表生 50 个模糊品类页。

## 三、关键词与品类交叉：哪些页能吃到 unblocked / school 流量？

以下游戏天然适合打「unblocked games for school / games not blocked on Chromebook / no download」标签：

- Puzzle 全部（merge-numbers, bubble-pop, block-stack, number-link-2248, water-sort, ball-sort, word-search, sudoku-classic）
- Arcade 全部（neon-snake, brick-breaker, flappy-orb, space-shooter, doodle-jump, pinball-classic, pac-run, tetris-blocks, asteroid-dodge）
- IO 全部（cell-eater, snake-io, paper-io, diep-tanks, hole-io）
- Sports：penalty-kick, basketball-shoot, mini-golf, table-tennis
- Casual：memory-match, typing-race, coloring-book

**Action / Racing / Strategy 类打 unblocked 标签要克制**，这些在学校网络里更容易被过滤，优先打「browser / no download / free online」即可。
