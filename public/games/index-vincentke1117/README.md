# 🐍 贪吃蛇游戏

一个使用 HTML5 Canvas 开发的现代化网页版贪吃蛇游戏，具有精美的深色主题 UI 和流畅的游戏体验。

## ✨ 特性

- 🎮 **经典玩法**：原汁原味的贪吃蛇游戏体验
- 📱 **响应式设计**：完美适配桌面端和移动端
- 🎯 **流畅控制**：支持键盘方向键和触屏滑动操作
- 🏆 **计分系统**：实时计分并保存历史最高分
- ⏸️ **暂停功能**：支持随时暂停/继续游戏
- 🌙 **深色主题**：护眼的现代化深色界面

## 🚀 在线试玩

👉 [点击这里开始游戏](https://snake-game-rho-henna.vercel.app/)

## 📦 本地运行

```bash
# 克隆仓库
git clone https://github.com/vincentke1117/snake-game.git

# 进入项目目录
cd snake-game

# 在浏览器中打开 index.html
# 或使用简单的 HTTP 服务器
python3 -m http.server 8000
```

## 🎮 操作说明

### 桌面端
- `↑ ↓ ← →` 或 `W A S D` - 控制蛇移动方向
- `空格键` - 暂停/继续游戏

### 移动端
- 滑动屏幕 - 控制蛇移动方向
- 点击方向按钮 - 精确控制
- 点击暂停按钮 - 暂停/继续游戏

## 🛠️ 技术栈

- **HTML5** - 页面结构
- **CSS3** - 样式设计（深色主题、动画效果）
- **JavaScript** - 游戏逻辑（原生 ES6+）
- **Canvas API** - 游戏画面渲染
